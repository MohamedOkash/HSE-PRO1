HSE Management System — Standalone Package
==========================================

QUICK START (Windows):
  Double-click setup.bat
  OR: npm install && npm run dev

QUICK START (Mac/Linux):
  ./setup.sh
  OR: npm install && npm run dev

REQUIREMENTS:
  Node.js 18 or newer — https://nodejs.org

OPEN IN BROWSER:
  http://localhost:3000

BUILD FOR PRODUCTION:
  npm run build
  (output in dist/ folder)

LOGIN:
  Use the credentials configured in the Firebase project.
  The Firebase configuration is already embedded in the app source.
